                     1. const

            after ES6 :
                      1. let     --> ek variable ko ek baar declear ke skte ho ( kyoki ek variable ko ek location box alot) , initialise only once but we can update any times

                      2. var     --> take last updated value.( updated value can be any type

                                    * Can be redeclared and reassigned.
                      3. const   --> only ones can declear.
